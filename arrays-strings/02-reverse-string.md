## Problem: Reverse String (Easy)

**Link:** [LeetCode 344](https://leetcode.com/problems/reverse-string/)

### Approach

Reverse the mutable character list in place. This avoids allocating a second list and matches the problem's in-place requirement.

### Complexity

- Time: O(n)
- Space: O(1)

### Notes

An empty list and a single-character list are already reversed.
